# Anton-s-Keyboard
---

## What is this project

* This project is just a keyboard using 2 PCB layers. It has hotswapable switches and LEDs bellow every cap. The little oled screen will be used for brightens and lighting for the led. The rotary encoder will be volume controll. 
---
## Why i made this project
* My keyboard is starting to have some switches a little more squishi or lose compared to others. Also some of the keycaps are worn down.
* In conclusion I want to change my old keyboard with this one.

# Assembly steps
* First the smaller parts must be souldered first because it will be harder to soulder the smaller components once the larger ones are placed / souldered.
* Secondly the larger components are souldered.
* Thirdly the foam is placed in the bottom case.
* After that all of the other parts are placed on the foam and closed off with the top plate.
* Finaly the cable can be connected to the PC and keyboard.
